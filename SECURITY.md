# Security Policy

## Supported Versions

We actively support the latest releases of the ACAS Methodology API with security updates and logic bug fixes.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a potential security issue or a critical error in the calculation logic, please follow these guidelines:

1. **Do not create a public GitHub Issue** for critical vulnerabilities to avoid exposing potential security risks.
2. Please contact the project maintainer directly via the contact information listed in the GitHub profile ([@aleksandrovd2-dev](https://github.com/aleksandrovd2-dev)).
3. Provide a clear description of the issue, steps to reproduce it, and any relevant code snippets or payloads.

We appreciate your responsible disclosure and will address reported issues as quickly as possible.
