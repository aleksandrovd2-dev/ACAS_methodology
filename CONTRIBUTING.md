# Contributing to ACAS Methodology

Thank you for your interest in contributing to the ACAS (Aleksandrov Customer Activity Scoring) project!

## How to Contribute

### 1. Reporting Bugs
* Check existing issues to make sure the bug hasn't been reported yet.
* Open a new issue with a clear title, reproduction steps, and expected behavior.

### 2. Suggesting Enhancements
* Open an issue describing the feature or methodology improvement you would like to see.
* Explain why this enhancement would be useful to the project.

### 3. Submitting Pull Requests
1. Fork the repository.
2. Create a feature branch based on the target branch (`ACAS_FastAPI_(eng)`, `ACAS_FastAPI_(rus)`, or `ACAS_templates`).
3. Make your changes and write clear, descriptive commit messages.
4. Ensure all Python code follows standard PEP 8 rules and mathematical logic remains accurate.
5. Open a Pull Request referencing your issue or proposed changes.
